Before publishing:
1. In index.html, replace YOUR_EMAIL, YOUR_LINKEDIN_URL and YOUR_YOUTUBE_URL.
2. Replace the Showreel placeholder with a YouTube/Vimeo iframe.
3. Replace the gradient project images with real stills.
   Easiest method:
   - Put images in this folder, e.g. blue-light.jpg
   - In styles.css change .image-1 to:
     background-image: url('blue-light.jpg');
4. Rename/remove projects as needed.

The design intentionally uses system fonts only, so there are no font licensing or loading issues.
